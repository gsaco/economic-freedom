# Results Index

This descriptive atlas builds a quinquennial global panel (1970-2020) for Economic Freedom of the World (EFW)
and selected macro indicators. Outputs emphasize coverage, distributions, ranks, maps, and co-movement patterns.

Reproduce:
- `make all`
- or `python tools/run_all.py --stage all`
