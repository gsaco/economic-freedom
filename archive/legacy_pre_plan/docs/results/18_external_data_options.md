# Opciones externas (internet) para ampliar potencia

## CLEA (Constituency‑Level Elections Archive)
- Cobertura muy amplia de elecciones legislativas (múltiples países y décadas).
- Útil para construir márgenes cerrados a nivel distrital y aumentar N efectivo.

## National Elections Database (NED)
- Cobertura global de elecciones presidenciales y parlamentarias.
- Contiene votos y escaños por partido; útil para márgenes top‑2 si se logra mapear ideología.

## DPI (Database of Political Institutions)
- Incluye ideología/afiliación partidaria y fragmentación legislativa.
- Puede ayudar a codificar “market vs non‑market” sin ParlGov.

## NELDA
- Registra eventos electorales a nivel nacional para regímenes democráticos y no democráticos.
- Complemento para verificar cambios de régimen / episodios de elecciones competitivas.

## Interpretación
Estas fuentes permitirían **aumentar potencia** o **mejorar mediciones** (márgenes más finos, ideología más consistente). La principal dificultad es el **match de partidos/ideología** entre bases.
