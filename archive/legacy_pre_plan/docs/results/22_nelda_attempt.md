# NELDA (National Elections Across Democracy and Autocracy)

## Qué se hizo
- Se descargó NELDA desde Harvard Dataverse (archivo `.tab`) y su codebook.
- Se verificó la disponibilidad de variables de votos/márgenes.

## Resultado
- NELDA **no contiene vote shares** ni márgenes continuos.
- Contiene variables cualitativas sobre competitividad, fraude, etc.

## Interpretación
NELDA **no es adecuada** para RD con margen continuo. Puede servir para análisis descriptivos o eventos discretos (competitividad), pero no como sustituto de un running variable tipo vote‑margin.
