# Economic Freedom RD/IV Pipeline

This repository executes `plan.tex` end‑to‑end, producing the close‑election RD spine, RD‑IV extensions, and publication‑ready tables/figures.

## Start here
- `docs/02_repo_contract.md` — how to run everything, dependencies, and runtime notes
- `docs/06_results_manifest.md` — generated tables/figures and their paths
- `docs/03_data_sources.md` — data access, licensing, and fallbacks

## Quickstart
```bash
make setup
make run
```

## Reproduce from scratch

```bash
make repro
```
